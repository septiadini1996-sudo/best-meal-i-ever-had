One sentence about the best meal I ever had: my grandmother's beef rendang, eaten with my fingers off a banana leaf on her porch in Padang while the rain hammered the tin roof. The program writes the single sentence to `entry.txt` in the output directory, exactly as the judge reads it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
